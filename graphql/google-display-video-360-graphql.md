# Google Display & Video 360 GraphQL API

Google DV360 is a demand-side platform for programmatic media buying. The API covers advertiser management, insertion orders, line items, targeting options, creatives, channels, and reporting.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Google Display & Video 360 REST API
**Documentation:** https://developers.google.com/display-video/api/reference/rest
